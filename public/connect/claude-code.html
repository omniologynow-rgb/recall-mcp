Recall + Claude Code

One command. Claude Code remembers across sessions, projects, and machines — and everything it learns is there in your other AI clients too.

What you need

  • A Recall API key — free in 30 seconds
  • Claude Code installed

One command

claude mcp add --transport http recall https://recall-mcp.fly.dev/mcp --header "Authorization: Bearer recall_live_YOUR_KEY_HERE"

Add --scope user to make it available in every project. Verify with /mcp inside Claude Code — you should see recall connected with five tools.

Or via .mcp.json

To share the config with a project (keeping the secret in an environment variable):

{
  "mcpServers": {
    "recall": {
      "type": "http",
      "url": "https://recall-mcp.fly.dev/mcp",
      "headers": { "Authorization": "Bearer ${RECALL_API_KEY}" }
    }
  }
}

Make the memory grow

Add a line to your CLAUDE.md so memory compounds without effort:

As we work, save durable facts, decisions, and my preferences with Recall's remember tool; check recall before asking me things I've told you before.

The 30-second test

Tell Claude Code: Remember that my dog is named Biscuit.
Open a new session (or a different client entirely). Ask: What's my dog's name?
If it says Biscuit — your memory is live everywhere.
