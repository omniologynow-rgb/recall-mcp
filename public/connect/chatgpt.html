Recall + ChatGPT

ChatGPT's built-in memory stays inside ChatGPT. Recall gives it a memory that also lives in Claude, Cursor, and whatever you use next.

What you need

  • A Recall API key — free in 30 seconds
  • A ChatGPT plan with connectors (Plus/Pro/Business) and developer mode enabled
ChatGPT's connector dialog has no header field, so your key rides in the URL. Issue a dedicated key for it (label it "chatgpt") so you can revoke it independently — see managing keys.

Steps

  1. In ChatGPT, open Settings → Apps & Connectors (name varies slightly by version — look for "Connectors").
  2. Under Advanced settings, turn on Developer mode.
  3. Click Create (new connector). Name it Recall.
  4. MCP server URL (with your real key): 
    https://recall-mcp.fly.dev/mcp?key=recall_live_YOUR_KEY_HERE
  5. Authentication: No authentication (the key in the URL is the auth). Confirm and create.
  6. In a new chat, enable the Recall connector from the composer's tools menu (developer-mode connectors are opt-in per conversation).

OpenAI moves these menus around; if the labels differ, search settings for "connectors" and "developer mode."

Make the memory grow

Add a line to ChatGPT's custom instructions so memory compounds without effort:

As we talk, save meaningful facts, preferences, and moments with Recall's remember tool; check recall before asking me things I've told you before.

The 30-second test

Tell ChatGPT: Remember that my dog is named Biscuit.
Open Claude (or any other connected client). Ask: What's my dog's name?
If it says Biscuit — one memory, two rival AIs, zero copy-paste.
