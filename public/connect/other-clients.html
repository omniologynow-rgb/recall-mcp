Recall + everything else

Gemini CLI, GitHub Copilot, Cline, and Le Chat — same memory, four more doors. You'll need an API key. If your client isn't here either, the universal guide covers every MCP client ever made (or not yet made).

Gemini CLI

Add to ~/.gemini/settings.json:

{
  "mcpServers": {
    "recall": {
      "httpUrl": "https://recall-mcp.fly.dev/mcp",
      "headers": { "Authorization": "Bearer recall_live_YOUR_KEY_HERE" }
    }
  }
}

Verify with /mcp inside Gemini CLI.

GitHub Copilot (VS Code)

Create .vscode/mcp.json in your workspace (or add via the "MCP: Add Server" command):

{
  "servers": {
    "recall": {
      "type": "http",
      "url": "https://recall-mcp.fly.dev/mcp",
      "headers": { "Authorization": "Bearer recall_live_YOUR_KEY_HERE" }
    }
  }
}

Tools appear in Copilot Chat's agent mode tool picker.

Cline

Cline → MCP Servers → Remote Servers → add name recall and the URL, or edit cline_mcp_settings.json:

{
  "mcpServers": {
    "recall": {
      "type": "streamableHttp",
      "url": "https://recall-mcp.fly.dev/mcp",
      "headers": { "Authorization": "Bearer recall_live_YOUR_KEY_HERE" }
    }
  }
}

Le Chat (Mistral)

Le Chat's connector dialog takes a URL with no header fields, so the key rides in the URL — issue a dedicated key (label it "lechat") so you can revoke it independently:

  1. Le Chat → Connectors (or Intelligence → Connectors) → Add connector → Custom MCP connector.
  2. Name it Recall, paste the URL: 
    https://recall-mcp.fly.dev/mcp?key=recall_live_YOUR_KEY_HERE
  3. Enable it in the chat's tools menu.

The 30-second test

Tell your AI: Remember that my dog is named Biscuit.
Open a different client. Ask: What's my dog's name?
If it says Biscuit — your memory is live everywhere.
