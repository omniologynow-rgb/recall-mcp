Recall + Claude (claude.ai)

Give Claude a memory that survives every new chat — and follows you to every other AI.

What you need

  • A Recall API key — free in 30 seconds
  • A paid claude.ai plan (custom connectors are available on Pro/Max; on Team/Enterprise an admin may need to add it)
The claude.ai connector dialog takes a URL with no header fields, so your key rides in the URL. Issue a dedicated key for it (label it "claude") so you can revoke it independently — see managing keys.

Steps

  1. In claude.ai, open Settings → Connectors (under "Extensions and connectors" on some plans).
  2. Click Add custom connector.
  3. Name it Recall and paste this URL (with your real key): 
    https://recall-mcp.fly.dev/mcp?key=recall_live_YOUR_KEY_HERE
  4. Click Add. No OAuth screen appears — the key is the auth.
  5. In a chat, open the search & tools menu and make sure Recall's tools are enabled.

Claude Desktop picks up the same connector automatically (connectors sync with your claude.ai account). For the terminal, see Claude Code.

Make the memory grow

Add a line like this to your Claude profile preferences so memory compounds without effort:

As we talk, save meaningful facts, preferences, and moments with Recall's remember tool; check recall before asking me things I've told you before.

The 30-second test

Tell Claude: Remember that my dog is named Biscuit.
Start a new chat. Ask: What's my dog's name?
If it says Biscuit — your memory is live. Now connect your other clients to the same key family and they'll know Biscuit too.
