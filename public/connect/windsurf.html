Recall + Windsurf

Cascade remembers your conventions and decisions — across sessions, and across every other AI client you connect.

What you need

  • A Recall API key — free in 30 seconds
  • Windsurf with MCP enabled (Settings → Cascade → MCP)

Steps

  1. Open ~/.codeium/windsurf/mcp_config.json (Windsurf Settings → Cascade → MCP → "Configure" opens it for you).
  2. Add the Recall entry: 
    {
  "mcpServers": {
    "recall": {
      "serverUrl": "https://recall-mcp.fly.dev/mcp",
      "headers": { "Authorization": "Bearer recall_live_YOUR_KEY_HERE" }
    }
  }
}
  3. Refresh MCP servers in Windsurf — Recall should list five tools.

If your version doesn't send headers

Older Windsurf builds don't pass headers to remote servers. Two fallbacks, either works:

// 1. key-in-URL (issue a dedicated key you can revoke):
{ "mcpServers": { "recall": {
  "serverUrl": "https://recall-mcp.fly.dev/mcp?key=recall_live_YOUR_KEY_HERE"
} } }

// 2. stdio bridge via mcp-remote:
{ "mcpServers": { "recall": {
  "command": "npx",
  "args": ["-y", "mcp-remote", "https://recall-mcp.fly.dev/mcp",
           "--header", "Authorization: Bearer recall_live_YOUR_KEY_HERE"]
} } }

The 30-second test

Tell Cascade: Remember that my dog is named Biscuit.
Start a new conversation — or a different client entirely. Ask: What's my dog's name?
If it says Biscuit — your memory is live everywhere.
