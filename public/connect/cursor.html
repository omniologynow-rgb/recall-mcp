Recall + Cursor

Your preferences, project decisions, and coding conventions — remembered across every Cursor session, and shared with your other AI clients.

What you need

  • A Recall API key — free in 30 seconds
  • Cursor (any recent version with MCP support)

Steps

  1. Open (or create) ~/.cursor/mcp.json for all projects, or .cursor/mcp.json in one project.
  2. Add the Recall entry: 
    {
  "mcpServers": {
    "recall": {
      "url": "https://recall-mcp.fly.dev/mcp",
      "headers": { "Authorization": "Bearer recall_live_YOUR_KEY_HERE" }
    }
  }
}
  3. Check Cursor Settings → MCP — Recall should show connected with five tools (remember, recall, list_memories, update_memory, forget).

Make the memory grow

Add a rule (Cursor Settings → Rules) so memory compounds without effort:

As we work, save durable facts, decisions, and my preferences with Recall's remember tool; check recall before asking me things I've told you before.

The 30-second test

Tell Cursor's agent: Remember that my dog is named Biscuit.
Open a new chat — or a different client entirely. Ask: What's my dog's name?
If it says Biscuit — your memory is live everywhere.
