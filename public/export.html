Your data leaves with you. Anytime.

Ownership isn't a feature, it's the point. One call returns everything you've ever stored — every memory, every namespace, every persona — as plain JSON. No ticket, no waiting period, no "contact sales."

Export everything

curl -o recall-export.json \
  -H "Authorization: Bearer recall_live_..." \
  https://recall-mcp.fly.dev/api/export

The response is a single self-describing document:

{
  "format": "recall.export",
  "format_version": 1,
  "exported_at": "2026-08-19T12:00:00.000Z",
  "account": { "user_id": "…", "email": "…", "tier": "free", "created_at": "…" },
  "memory_count": 42,
  "namespaces": ["default", "preferences", "persona"],
  "memories": [
    {
      "id": "…",
      "namespace": "preferences",
      "content": "Prefers Python for data analysis.",
      "metadata": { "source": "conversation" },
      "created_at": "…",
      "updated_at": "…"
    }
  ]
}

Personas are memories too — they live in namespaces, so they're always included. Embedding vectors are not exported: they're derivable from content and provider-specific; your content, metadata, and timestamps are the portable truth.

Deletion is real, too

The forget tool deletes by ID instantly, or by query with a two-step preview → confirm flow so nothing bulk-deletes by accident. Deleted means deleted — there is no shadow copy, and your memories are never used to train models.
