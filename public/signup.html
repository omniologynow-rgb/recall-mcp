Managing keys

Everything is self-serve over the API using any active key:

# issue an additional key (e.g. a dedicated one per client)
curl -X POST https://recall-mcp.fly.dev/api/keys \
  -H "Authorization: Bearer recall_live_..." \
  -H "Content-Type: application/json" -d '{"label":"chatgpt"}'

# list your keys
curl https://recall-mcp.fly.dev/api/keys \
  -H "Authorization: Bearer recall_live_..."

# rotate a key (new secret issued, old one revoked, atomically)
curl -X POST https://recall-mcp.fly.dev/api/keys/<key-id>/rotate \
  -H "Authorization: Bearer recall_live_..."

# revoke a key
curl -X DELETE https://recall-mcp.fly.dev/api/keys/<key-id> \
  -H "Authorization: Bearer recall_live_..."
